# IMDb Movie Review Sentiment Analysis Model

A Machine Learning model designed to perform sentiment analysis on IMDb movie reviews, accurately classifying reviews as either **Positive** or **Negative**.

---

## 📌 Project Overview
This project uses binary text classification techniques to analyze the sentiment of movie reviews. By processing raw text inputs, the trained model predicts whether a viewer's opinion of a movie is overall positive or negative.

## 📊 Model Performance & Results
- **Accuracy:** **84.4%**
- **Task Type:** Binary Text Classification (Positive / Negative)
